# Кулинар и фуд-блогер

Страница «О себе» кулинара и фуд-блогера: навыки, проекты-рецепты и форма обратной связи.

## Возможности

- Карточки проектов: при наведении фон карточки размывается.
- Подсветка полей формы при фокусе.
- Навигация по разделам страницы.

## Запуск

Открыть `index.html` в браузере.
