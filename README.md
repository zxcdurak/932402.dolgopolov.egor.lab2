# Кулинар и фуд-блогер

Персональная страница-визитка кулинара и фуд-блогера. На ней можно быстро познакомиться с автором: узнать, что он умеет, посмотреть его кулинарные проекты и написать ему.

## Для кого

- Читатели блога, которые хотят узнать об авторе больше.
- Бренды, кафе и рестораны, которые ищут фуд-блогера для сотрудничества.

## Функциональность MVP

- **Профиль автора** — имя, специализация и фото фирменного блюда.
- **Навыки** — список кулинарных компетенций автора.
- **Проекты** — карточки рецептов с кратким описанием. При наведении фон карточки размывается, и внимание переходит на текст. Самый популярный рецепт отмечен меткой «Хит».
- **Обратная связь** — форма с полями «Имя», «Email» и «Сообщение». Активное поле подсвечивается жёлтой обводкой.
- **Навигация** — ссылки для быстрого перехода к разделам. Посещённые ссылки выделяются цветом.
- **Любимая кухня** — боковой блок о кулинарных предпочтениях автора.

## Запуск

Открыть `index.html` в браузере.
